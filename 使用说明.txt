文档压缩标准化工具 - 使用说明

一、打开工具
1. 双击“文档压缩标准化工具.html”，立刻打开，不需要安装任何东西。
2. 这个 HTML 是单文件：脚本和样式全部打包在里面，
   不联网、不启动服务、不产生后台窗口，可以单独复制到桌面或 U 盘使用。
3. 如果这个文件不小心删了，双击“一键启动.bat”会自动重新构建一次
   （这一步需要本机装有 Node.js，仅首次需要）。

二、粘贴转换（公式与化学式）
把 AI 聊天框里的内容整段粘贴到左侧输入区，右侧会立刻显示转换后的效果：

- 数学公式（$...$、$$...$$、\(...\)、\[...\]）→ 导出的 Word 里是“原生公式”，
  双击就能编辑，Word 的公式工具、字号调整都能用。
- 化学式与离子（H2SO4、Ca(OH)2、CuSO4·5H2O、Fe3+、SO42-、\ce{...}）→
  Word 里是真实的上下标，不是替代字符，可以直接改。
- 零散的 \alpha、x^2 这类写法会转成 α、x² 这样的普通字符。
- 不想转换时，可以在“精细处理选项”里关掉对应开关。

详细的支持范围与无法识别的情况，见「设置 → 处理工作流 → 规则说明」，或 README.md。

三、题目分级（■ ◆ ▸）
以前所有题号都是一样的方块，看不出哪是大题、哪是小题。现在会自动分层：

- ■ 大题：一、选择题 / （二）填空题 / 第一部分
- ◆ 小题：1. 下列各题… / 第3题 / Q3
- ▸ 小问：（1）求… / 1) 求…
- 选项 A. B. C. D. 不加符号，只缩进，避免抢走重点；
  “一、二、三”式选项因为和大题长得一模一样，会加上 ◇ 以示区别。
- Word 里大题字号略大 + 加粗 + 段前留白，小题加粗，小问缩进，
  一眼就能看出题目结构；原有题号文字不改，只在前面补符号。

它是怎么认的（三条证据）：
1. 序号字符集：中文数字 → 大题，阿拉伯数字 → 小题，（1）→ 小问；
2. 递增序列：只认“上一个大题 +1”，序号断裂就不当大题（防止选项被当标题）；
3. 题干关键词：出现“选择题/填空/解答/计算/证明”等，直接认作大题。
另外：连续 3 行以上的“一、二、三”短句会被当成选项组；“3.14”这类小数不动；
公式块和代码块内部完全不处理。识别不了就保持原样，绝不乱加符号。

四、表格与列表
AI 输出的 Markdown 表格会变成 Word 原生表格（能改单元格、表头跨页自动重复），
“- ”开头的条目会变成 Word 的项目符号列表，不再是纯文本短横线。

五、空白压缩与分隔标号
从 AI 聊天框复制来的文本经常带着一大串看不见的空格和整段空行，白白吃掉版面。
“精细处理选项”里的“空白压缩 + 分隔标号”开关（默认开启）专门处理这个：

- 行内连续 3 个以上的空格/制表符/全角空格 → 压成 1 个半角空格；
  连续 2 个以内视为有意留白（中英文间距、手工对齐），原样不动。
- 行尾多余空格全部删除；文首、文尾的空行直接丢掉。
- 行首缩进 4 格以内保留（段首缩进、嵌套列表不会被破坏），超过 4 格的粘贴垃圾压成 2 格。
- 连续 3 个以上空行 → 换成一行“──── ◆ ────”分隔标号；
  1~2 个空行属于正常段落间隔，保留不动（否则全篇会糊成一片）。
- 分隔标号在 Word 里居中、灰色、略小字号：比 3 行空白省版面，又比直接删掉更醒目。
- 公式块（$$ … $$，可跨行）和 ``` 代码块内部完全不压缩，避免破坏公式语法。
- 不新增、不删除任何可见文字，只压缩间隔；关掉开关则原文一个字符都不动。

六、截图裁切排版
左侧“核心功能菜单”第三项。手机截长图、网页截屏常带顶部状态栏、底部导航条和一圈黑边，
这一页就是用来把它们批量裁干净、再按纸张排版的。

1. 导入：把多张截图直接拖进窗口，或点右上角“导入截图”。支持 PNG / JPG / WebP。
   文件名里带 20240512_182233 这类时间戳的，会按拍摄顺序自动排好。
2. 自动识别：导入后每张图会自动算出上、下两条红色裁切线，灰色区域就是要被裁掉的部分。
   打开“左右自动裁边”后，两侧的深色黑边（视频截图、录屏常见）也会一起剥掉；
   这个开关默认关闭，普通截图的结果与以前完全一致。
3. 微调：
   - 按住红色“TOP ↕ / BOT ↕”手柄上下拖动，“LEFT ↔ / RIGHT ↔”左右拖动，只改当前这一张；
   - 手柄按 Tab 选中后，可用方向键微调 10px，按住 Shift 为 50px；
   - “首图比例同步”：以第 1 张的四边比例为准，等比套给所有图（同一台设备连续截图最省事）；
   - “模板学习”：给一张原图 + 它对应的已裁好样本，程序反推左右上下四条边再套用到全部截图。
     样本顶部是大片白边、样本被缩放导出过、左右也裁过，都能正确识别；样本和原图对不上时
     会明确提示“相似度不足”，不会把错的裁切套到所有图上；
   - 顶部“黑边阈值”越大越容易把浅灰区域当黑边裁掉；“避让底部蓝钮”用来躲开截图工具/悬浮球。
     锁定模板后这三项自动置灰，清除模板即可恢复。
4. 右侧预览：
   - 白纸上的位置、留白与最终导出的 PDF 完全一致；
   - “－ / ＋”可把预览放大到 75%~250%，查看细节，点“适应”回到 100%；
   - 点任意一页缩略图，会滚动定位到对应的编辑卡片。
5. 导出（右下角）：
   - 单张 PNG：卡片底部的“单张”；
   - 打包 ZIP：全部裁切图按 001、002… 编号打包，中文名正常显示；
   - 导出 PDF：每页一张图，等比居中，边距可设 0~30mm；纸张可选 A4（默认）/ A5 / A3 / Letter，
     文件名会带上纸张，例如“截图裁切排版_3页_A5.pdf”。
   - 导出成功后按钮会闪一下、状态栏出现对勾提示，不需要任何额外点击。
6. 全部处理都在本机内存完成，图片不会上传，也不依赖任何在线库。

注意：
- 纯白背景、没有黑边的截图，阈值太高会把正文上方的留白一起裁掉，把阈值调小即可；
- 深色模式（夜间）截图本身页面就是暗的，自动识别会失效，请用模板学习或手动拖线；
- 导出的 PDF 是图片型页面，文字不能选中，需要可编辑文字请回到“快速排版工作区”导出 Word。

七、设置窗口（排版标准 / 处理工作流 / 通用 / 关于）
左侧“核心功能菜单”最下面的“设置”会打开一个独立的设置窗口，用法与 Windows 11 的“设置”一致：

- 左边是分类导航，鼠标点击或按 ↑ / ↓ 方向键切换，右边显示对应的设置卡片。
- 排版标准：选字体、字号、行距、页边距、段前段后空距；
  可“另存为我的专属模板”，或“恢复出厂模板”（会删掉全部自定义模板）。
- 处理工作流：原来独立成页的“自定义工作流”已经并进来了。逐条开关流水线步骤，
  每条都标出“运行中 / 已跳过”，底部可一键全部启用或全部禁用；
  下方法规说明（题目分级依据、空白压缩规则、粘贴转换支持范围）收在折叠区里，点开才展开。
- 通用：主题模式（浅色 / 深色 / 跟随系统），以及“恢复默认设置”
  （清除浏览器里保存的主题偏好和自定义模板，页面会自动刷新）。
- 关于：版本、运行方式与能力摘要。
- 也可以按 Ctrl + , 直接打开设置。
- 按 Esc、点击窗口外的灰色区域、或点右上角 × 都能关闭；
  关闭后键盘焦点会回到“设置”菜单项。
- 所有改动即时生效并自动保存在本机浏览器，不会上传、不联网。

八、特点
- 完全离线运行，不需要联网，不需要任何 API Key。
- 打开后就是一个普通网页，关闭浏览器标签页即退出。
  没有后台黑窗口，不用管“不要关闭窗口”之类的注意事项。

九、常见问题
1. 双击 HTML 后浏览器打不开或显示空白：
   右键该文件 → “打开方式” → 选择 Edge / Chrome 即可。
   （工具是纯前端页面，推荐用较新的浏览器。）

2. 想换台电脑用：
   只把这一个“文档压缩标准化工具.html”拷过去就能用，
   不需要拷 node_modules、src 等开发文件。

3. 导出的 Word 文件在哪里？
   通过浏览器下载保存，一般在“下载”文件夹，
   也可以在浏览器下载弹窗中选择保存位置。

4. 公式没能识别成 Word 公式？
   AI 输出里的公式一般带 $ 或 \( \) 定界符才能被识别成“公式对象”。
   没有定界符的长公式只会做符号替换（α、√、² 等），这是刻意的保守策略，
   避免把普通文字误判成公式。

5. 化学式被漏掉或被误认？
   CO、MP3、USB3 这类本身有歧义的缩写属于正常边界情况，
   可以把“化学式 → 真实上下标”开关关掉，避免误转换。

6. 题号分错了层级（比如某行被当成大题，或该加 ◆ 却没加）？
   多半是「序号不连续 + 标题里没有关键词」，工具宁可不动也不乱加。
   改法：把该行写成“二、填空题”这类带题型词的形式，或干脆手动补 ■ ◆ ▸，
   工具遇到已有的符号会跳过，不会重复加。
   另外纯要点罗列的“1. 2. 3.”会和小题同样标 ◆，这是作业场景的取舍。

7. 不想看到“──── ◆ ────”这条分隔线？
   关掉“空白压缩 + 分隔标号”开关即可（原文恢复原样）。
   如果只想保留分隔线、不要其它压缩，目前是同一开关控制，可以告诉我，
   我把它拆成两个独立开关。

8. 想改代码后实时预览：
   在本文件夹运行 npm install（首次），再运行 npm run dev，
   然后访问 http://localhost:5173。
   改完执行 npm run build，会重新生成根目录的“文档压缩标准化工具.html”。
